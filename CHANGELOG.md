# CHANGELOG

## v1.0.0 — 2026-10-02

- Primera versión del servidor remoto de control para Asthi Sender.
- Autenticación administrativa.
- Gestión de usuarios.
- Cinco slots de claves.
- Activación/desactivación remota.
- Revocación de sesiones al bloquear usuarios.
- Registro de instalaciones.
- Endpoint de salud `/salud`.
- Heartbeat para clientes.
- Panel web administrativo básico.
- PostgreSQL como almacenamiento persistente.
- Sin integración con WhatsApp API.
